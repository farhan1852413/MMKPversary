# MMKPversary 💖

A simple and aesthetic anniversary website made using pure HTML, CSS, and JavaScript.  
Built to celebrate a special milestone with animations, a live love timer, music, and a responsive photo gallery.

## Features
- ⏳ Live relationship timer
- 💕 Floating heart animations
- 🎵 Background music support
- 🖼️ Responsive image gallery
- ✨ Glassmorphism UI design

## Tech Used
- HTML
- CSS
- JavaScript
